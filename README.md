# BTC V3 自动化交易 · REAL DATA

这是 V3 自动化交易版的真实行情版本：**不再生成随机 OI、资金费率、多空比或价格数据**。

## 数据
- OKX BTC-USDT-SWAP 实时价格、标记价格、24h成交量
- OKX Open Interest
- OKX Funding Rate
- OKX Order Book 深度，用于盘口失衡
- OKX 15m / 30m / 1H K线
- OKX Rubik 公开统计：账户多空比（接口可用时）
- OKX Rubik 公开统计：主动买卖成交量（接口可用时）
- EMA / RSI / MACD / Bollinger Bands 均基于上述真实K线本地计算
- 价格/OI 联动、盘口失衡、主动成交、快速价格变化和 OI 变化用于 V3 信号

## 交易模式
- 默认模拟本金：$10,000
- 策略资金池：$3,000
- 单笔风险上限：1.5%
- 日亏损上限：3%
- 最大杠杆参数：10x
- 最多同时 1 仓
- 连续亏损保护：3 次
- **不会发送真实订单，不需要 API Key**

## 重要
GitHub Pages 负责展示前端；浏览器直接读取 OKX 公共行情。Safari 页面关闭后不能保证持续运行。如果未来要做到“浏览器关闭仍自动运行”，需要增加云端/服务器策略引擎。真实资金交易也必须另行接入经过权限控制的 OKX 私有 API，不能把 API Secret 放进 GitHub Pages 前端。

如果任何真实接口失败，页面显示“不可用”，**不会用随机数补齐**。
