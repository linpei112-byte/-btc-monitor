# BTC V3.2 自动化交易 · V16 检查修正版

本版本以 OKX BTC-USDT-SWAP 的公开实时市场数据为基础进行本地模拟，不连接真实资金。

## 当前参数
- 初始模拟本金：1,000 USDT
- 保证金：全仓（cross）模拟
- 杠杆：10x / 20x，由信号强度自动选择
- 页面加载后自动运行，不需要手动启动
- 人工按钮仅用于“暂停/恢复新开仓”，不会因为暂停而强制平掉已有持仓

## 实时数据
- OKX REST：历史 K 线、ticker、mark price、OI、当前资金费率、合约参数
- OKX WebSocket：ticker、mark-price、open-interest、funding-rate、trades、incremental books、1m/5m/15m/30m/1H K线
- 下单模拟使用实时订单簿吃单：开多吃 ask、开空吃 bid；平多吃 bid、平空吃 ask
- 未实现盈亏使用 OKX mark price
- 资金费在实际结算时间到达后，读取 OKX funding-rate-history 的 realizedRate 模拟结算

## 不盲目开仓
新开仓必须同时通过：
1. 核心行情数据新鲜度检查；
2. 多周期方向评分；
3. 1m/5m/15m 短周期至少两周期同向确认；
4. 主动成交方向确认；
5. OI 短时异常波动过滤；
6. 综合分达到最低开仓阈值。
任何一项不满足，系统继续盯盘和更新数据，但自动暂停新开仓。

## 自主短线退出
持仓后持续重新分析实时行情。系统不会设置固定收益目标，而是根据趋势反转、动能衰减、波动异常、盈利回撤保护等实时条件自主退出。数据异常时优先保护已有持仓，不盲目继续开新单。

## 逐笔订单历史
每一笔订单从开仓开始就创建唯一 Order ID，并在同一条历史记录中持续更新到平仓。记录包括：开仓/平仓时间、方向、开平仓价格、杠杆、全仓模式、保证金、合约数量、名义价值、手续费、资金费、毛/净盈亏、单笔收益率、持仓时长、平仓原因、平仓后权益、最大有利/不利波动。历史订单数量不截断。

## 收益统计
页面实时统计总订单、累计净收益、累计收益率、胜率、盈利/亏损单、最大单笔盈利、最大单笔亏损、最大回撤和当前账户权益。

## 持久化
模拟账户快照同时写入 LocalStorage、IndexedDB 和 Cache Storage，并在页面隐藏/关闭时保存。订单历史不会因普通刷新或重新打开同一浏览器来源而主动清空。清除 Safari 网站数据、使用私密浏览或更换设备/网站来源仍可能导致本地记录不可见；跨设备永久保存需要后端数据库。

## 安全边界
这是浏览器本地模拟交易，不会向 OKX 发送真实下单请求，也不会动用真实资金。以后若接 OKX 官方模拟盘/实盘 API，需要另外实现认证、订单状态回报和服务器端持久化。
